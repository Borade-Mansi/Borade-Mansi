# 💫 About Me:
Hi 👋, I'm Mansi Borade.<br><br>I am a passionate and ambitious cybersecurity MSc student at the University of the West of Scotland (London), specializing in SOC operations, threat detection, security monitoring, AI security, and intelligent automation. I am highly interested in building practical and scalable cybersecurity solutions that combine modern security operations with AI-driven technologies to improve threat detection, incident response, and proactive cyber defense strategies.  <br><br>My technical interests include SOC operations, SIEM engineering, phishing detection, threat hunting, log analysis, security analytics, cloud security, and AI-assisted cybersecurity systems. I enjoy working on projects that focus on identifying security threats, analyzing attack patterns, monitoring suspicious activities, and automating security workflows to strengthen organizational security operations.  <br><br>I have hands-on experience with Python, cybersecurity labs, SIEM-style monitoring, log analysis, and security tools such as Wireshark, Suricata, Snort, and other security monitoring technologies. Through internships, academic projects, cybersecurity simulations, and independent research, I continuously improve my practical knowledge in threat detection, defensive security operations, incident response, and intelligent security automation.  <br><br>In addition to cybersecurity, I am deeply interested in AI security and agentic engineering, particularly in how intelligent systems and automation can support SOC teams through automated threat analysis, alert triage, security monitoring, and incident response assistance. I am passionate about exploring the future of AI-powered cybersecurity and developing innovative solutions that make security operations more efficient, intelligent, and proactive.  <br><br>I am always eager to learn emerging technologies, collaborate on impactful cybersecurity projects, and contribute to modern security operations by combining cybersecurity expertise with intelligent automation and AI-driven defense systems.
